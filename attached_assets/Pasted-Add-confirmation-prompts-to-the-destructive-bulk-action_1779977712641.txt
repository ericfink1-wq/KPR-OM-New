Add confirmation prompts to the destructive/bulk actions in this app, but ONLY to the genuinely risky ones — leave everyday single edits and soft-deletes (moving to Trash) frictionless.

1. PERMANENT DELETE — in src/App.tsx, the Trash list has a "Delete permanently" button that calls handleDelete(d.id) directly with NO confirmation. Add a confirmation at that button's onClick: before calling handleDelete, show window.confirm(`Permanently delete "${name}"? This removes the deal, its images, and its source text from the database and cannot be undone.`) where name = d.propertyName || d.fileName || "this deal". Only call handleDelete if the user confirms.

2. BULK JSON UPLOAD — in src/components/Header.tsx, in handleJsonFiles, AFTER building the allDeals array but BEFORE the import loop runs, preview the impact against the existing `deals` prop. Count how many incoming deals match an existing non-trashed deal by propertyName (trimmed, lowercased) = "willUpdate", and the rest = "willAdd". If allDeals.length > 10 OR willUpdate > 0, show a window.confirm summarizing it, e.g.: `Import ${allDeals.length} deal(s)?\n\n${willUpdate} may UPDATE existing deals: ${updateNames.join(", ")}\n${willAdd} new deal(s) will be added.\n\nContinue?`. Say "may update" since matching is approximate. If the user cancels, abort the import entirely (clear any progress state). If it's a small upload with zero matches, proceed with no prompt.

3. BACKUP RESTORE — in src/components/Header.tsx, in handleRestore, after parsing the incoming deals but before applying them, count how many incoming ids match existing deal ids ("updates") vs new ("additions"), then show window.confirm: `Restore ${incoming.length} deal(s) from this backup?\n\n${updates} will overwrite existing deals.\n${additions} will be added.\nExisting deals are never deleted by a restore.\n\nContinue?`. If cancelled, abort.

Do not change any other behavior. Make, test, iterate until: permanent delete asks for confirmation and naming the deal; a JSON upload that would update existing deals (or is large) asks for confirmation showing the counts; a backup restore asks for confirmation showing the counts; and small everyday actions are unaffected.
