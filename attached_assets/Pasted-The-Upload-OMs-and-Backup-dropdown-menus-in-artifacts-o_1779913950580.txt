The Upload OMs and Backup dropdown menus in artifacts/om-database/src/components/Header.tsx are broken — clicking the trigger buttons does not show the dropdown panels.

ROOT CAUSE:
The header's scrollable wrapper around line 196 has `overflowX: "auto"` (added for mobile horizontal scrolling). Per CSS spec, setting overflow-x to "auto" implicitly sets overflow-y to "auto" as well, which creates a clipping context. The dropdown panels use `position: absolute` and are descendants of this wrapper, so they get clipped vertically when they extend below the header's 72px height. The state toggles work, the panels just aren't visible.

FIX: Render both dropdown panels (and their backdrop overlays) via React Portal directly into document.body. This bypasses the ancestor's clipping context. The dropdowns will be positioned with `position: fixed` using coordinates computed from the trigger button's getBoundingClientRect().
