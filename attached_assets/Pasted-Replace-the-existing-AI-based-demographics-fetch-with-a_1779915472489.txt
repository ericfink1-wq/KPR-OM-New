PART 1 — SERVER MODULE: artifacts/api-server/src/lib/demographics.ts (new file)

Export one function: fetchCensusDemographics(address: string): Promise<MarketDemographics | null>

Implementation steps:

1. GEOCODE THE ADDRESS — use the free US Census Geocoder:
   GET https://geocoding.geo.census.gov/geocoder/locations/onelineaddress?address={encodeURIComponent(address)}&benchmark=Public_AR_Current&format=json
   
   Parse: result.addressMatches[0].coordinates.x (longitude), .y (latitude). Also grab matchedAddress for logging.
   If no match returned, return { confidence: "low", source: "US Census Bureau", note: "Address could not be geocoded", lookedUpAt: new Date().toISOString() }.

2. FIND TRACTS WITHIN EACH RADIUS — use the TIGERweb spatial query (free, no key):
   For each radius in [1, 3, 5] miles:
     GET https://tigerweb.geo.census.gov/arcgis/rest/services/Census2020/Tracts_Blocks/MapServer/0/query?geometry={lng},{lat}&geometryType=esriGeometryPoint&distance={miles}&units=esriSRUnit_StatuteMile&inSR=4326&spatialRel=esriSpatialRelIntersects&outFields=GEOID,STATE,COUNTY,TRACT&returnGeometry=false&f=json
     
   Collect tract GEOIDs into three sets: tracts1mi, tracts3mi, tracts5mi.
   Note: 3mi will include all of 1mi's tracts; 5mi will include 3mi's. That's correct — these are nested rings.

3. PULL ACS 5-YEAR DATA — for each unique tract:
   The most recent ACS 5-year vintage as of build time (early 2026) is the 2024 vintage (covering 2020-2024 estimates), released December 2025. Use that if available; if the 2024 endpoint returns an error or empty, fall back to 2023 vintage.
   
   For each (state, county) combination, batch a single query:
   GET https://api.census.gov/data/{VINTAGE}/acs/acs5?get=B01003_001E,B19025_001E,B11001_001E&for=tract:*&in=state:{state_fips}+county:{county_fips}
   
   Variables:
     B01003_001E = Total Population
     B19025_001E = Aggregate Household Income
     B11001_001E = Total Households
   
   Response is a 2D array; the first row is the header. Parse rows into a map keyed by GEOID (state+county+tract = 11 digits).

4. AGGREGATE PER RADIUS:
   For each radius ring:
     pop{N}mi = sum of B01003_001E across the ring's tracts
     totalHH = sum of B11001_001E
     aggIncome = sum of B19025_001E
     avgHHI{N}mi = totalHH > 0 ? Math.round(aggIncome / totalHH) : null
   
   Round populations to nearest integer. Round avgHHI to nearest whole dollar.

5. BUILD AND RETURN the MarketDemographics object:
   {
     pop1mi, pop3mi, pop5mi,
     avgHHI1mi, avgHHI3mi, avgHHI5mi,
     confidence: "high",
     source: "US Census Bureau ACS 5-Year Estimates",
     asOf: "{startYear}–{endYear}",  // e.g., "2020–2024" — note: use en-dash not hyphen for the display
     note: null,
     sources: [
       { url: "https://www.census.gov/programs-surveys/acs", title: "American Community Survey 5-Year Estimates" }
     ],
     lookedUpAt: new Date().toISOString(),
   }

ERROR HANDLING — never throw. Wrap each external call in try/catch with a 10-second timeout per request. On any failure, return a MarketDemographics object with confidence: "low", a descriptive note, and lookedUpAt set. So the deal always gets demoChecked even if the fetch fails — prevents retry storms.

Add POST /api/deals/:id/refresh-demographics:

  if (savedDeal.address && !savedDeal.marketDemographics && !savedDeal.demoChecked) {
    // Fire-and-forget. Don't block the response.
    (async () => {
      try {
        const demo = await fetchCensusDemographics(savedDeal.address);
        if (demo) {
          await updateDeal(savedDeal.id, { 
            marketDemographics: demo, 
            demoChecked: new Date().toISOString() 
          });
        }
      } catch {}
    })();
  }

PART 4 — CLIENT API CLIENT: artifacts/om-database/src/lib/api.ts

Add:
  export async function apiRefreshDemographics(dealId: string): Promise<MarketDemographics | null> {
    const res = await fetch(`${API_BASE}/api/deals/${dealId}/refresh-demographics`, { 
      method: "POST", 
      credentials: "include" 
    });
    if (!res.ok) throw new Error(`Refresh failed: ${res.status}`);
    const data = await res.json();
    return data.marketDemographics ?? null;
  }
